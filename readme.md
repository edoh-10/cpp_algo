# ⚙️ C++ Exercises — Parcours d'apprentissage

> Une collection d'exercices C++ organisée par notion, du plus fondamental au plus avancé. Chaque dossier correspond à un concept du langage, avec du code commenté, des explications et — à terme — des tests.

## 🎯 Objectif

Ce repo documente mon apprentissage progressif du C++. L'idée : **un dossier = une notion**, avec pour chacune :
- le code des exercices,
- un README qui explique la notion,
- les pièges rencontrés (surtout côté mémoire !) et ce que j'ai appris.

L'ambition à terme : évoluer vers des structures de données et algorithmes plus avancés, puis vers du C++ moderne (RAII, smart pointers, templates).
